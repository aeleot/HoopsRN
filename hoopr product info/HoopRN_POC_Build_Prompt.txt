# HoopRN iOS App — Phase 0 POC: Tab Navigation & Google Maps Integration

## Objective
Build a functional proof of concept for the HoopRN iOS app that establishes the core three-tab navigation structure and successfully embeds an interactive Google Maps view with basketball court markers. This POC focuses on **presentation layer** and **map rendering** — no backend or real data integration yet.

---

## Technical Requirements

### 1. Project Setup & Dependencies
- **Target:** iOS 17.0+
- **Build System:** SPM (Swift Package Manager) for Google Maps SDK integration
  - Add GoogleMaps framework via CocoaPods (since SPM doesn't support Google Maps; use CocoaPods integrated with Xcode)
  - Alternative: Use GoogleMapsSDK-iOS if available via SPM
- **State Management:** MVVM architecture with @ObservedObject, @StateObject, and @EnvironmentObject
- **Data Persistence:** Keep SwiftData for now, but create a separate MVVM layer (do NOT mix SwiftData with view logic)
- **Location Services:** Enable NSLocationWhenInUseUsageDescription and NSLocationAlwaysAndWhenInUseUsageDescription in Info.plist

### 5. Location Services Setup

**Create `LocationManager.swift`** — Singleton MVVM manager:
- Conform to NSObject, CLLocationManagerDelegate
- Properties:
  - @Published var userLocation: CLLocationCoordinate2D?
  - @Published var authorizationStatus: CLAuthorizationStatus
  - private let locationManager = CLLocationManager()
- Methods:
  - requestLocationPermission() — Trigger "When In Use" permission dialog
  - startUpdatingLocation() — Begin location tracking
  - stopUpdatingLocation() — Stop tracking
- **Behavior:**
  - On first launch, do NOT auto-prompt for permission (wait for explicit action)
  - Store initial location when granted; update @Published properties
  - Gracefully handle .denied / .restricted states

### 6. View Hierarchy & Navigation

**File Structure:**
```
hoopr/
├── ContentView.swift (replaced or archived)
├── MainTabView.swift (new root)
├── Tabs/
│   ├── FindAMatchTab.swift (contains MapView)
│   ├── LocalGamesTab.swift (placeholder)
│   └── ProfileTab.swift (placeholder)
├── Views/
│   └── MapView.swift (Google Maps wrapper)
├── Managers/
│   └── LocationManager.swift
└── Models/
    └── CourtModel.swift (struct for demo courts)
```

**`MainTabView.swift` Structure:**
```swift
struct MainTabView: View {
    @StateObject private var locationManager = LocationManager()

    var body: some View {
        TabView {
            FindAMatchTab()
                .tabItem {
                    Label("Find a Match", systemImage: "map")
                }

            LocalGamesTab()
                .tabItem {
                    Label("Local Games", systemImage: "list.bullet")
                }

            ProfileTab()
                .tabItem {
                    Label("Profile", systemImage: "person.circle")
                }
        }
        .environmentObject(locationManager)
    }
}
```

### 11. Error Handling & Edge Cases

- **Google Maps API Key Missing:** Show error alert with black text on white background ("Maps API key not configured")
- **Location Permission Denied:** Use hardcoded center point (SF), disable "My Location" button
- **No Network:** Map should still render (Google Maps has offline caching)
- **Marker Tap Outside Safe Area:** Handle gracefully (no crash)
- **Low Memory:** Handle gracefully, no performance degradation
